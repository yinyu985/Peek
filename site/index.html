适用于 macOS 的窗口工具

把窗口收进屏幕边缘。

按快捷键收起暂时不用的窗口。想用时，再按一次，或把鼠标移回屏幕边缘。

下载 Peek ↗

macOS 13+ · Apple Silicon / Intel

按应用设置

同一块屏幕，
各有各的位置。

  • 给每个应用设置不同的快捷键和收起方向。
  • 调整窗口露出多少、悬停多久才展开。
  • 只想用快捷键？关闭自动收放即可。

首次使用

下载 DMG，拖进应用程序。

M 系列 Mac 选 arm64，Intel Mac 选 x86_64。首次运行时，需要在系统设置中给 Peek 授予辅助功能权限，才能移动窗口。

Peek 尚未经过 Apple 公证。若 macOS 拦截，请确认安装包来自 GitHub Releases，再按安装说明操作。
